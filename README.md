# sequel-library-manager

A web application allowing a library to manage it's collection of books. The app uses JavaScript, Node.js, Express, Pug, SQLite and the SQL ORM Sequelize.

Users can view the full list of books, search for particular books, authors or genres, add new books, as well as update or delete existing ones.

The app uses Sequelize to query the database to perform the create, search, update and deleting of books.

The app runs on port 3000 of localhost.
